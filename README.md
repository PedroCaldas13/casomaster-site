# Caso Master — site publicado

Conteúdo gerado. **Não edite nada aqui** — a cada publicação esta pasta é
sobrescrita por inteiro e qualquer alteração feita neste repositório se perde.

- Site no ar: <https://casobancomaster.com.br>
- Dados, gerador e histórico editorial: <https://github.com/PedroCaldas13/CasoMaster>

## O que tem nesta pasta

140 páginas HTML estáticas, mais o índice de busca, o sitemap e o CNAME
do domínio.

Tudo isso é gerado a partir de arquivos JSON no repositório de origem, onde vivem
154 registros com fonte, 89 entidades, 24 casos e 232 fontes catalogadas.
Nenhuma linha de HTML é escrita à mão, e o grafo é derivado dos dados, nunca desenhado.

Conteúdo atualizado até 14/09/2026.

## Correções

Erros se corrigem na origem, não aqui. Cada registro no site tem um botão que leva
ao canal de correção com o identificador já preenchido.
